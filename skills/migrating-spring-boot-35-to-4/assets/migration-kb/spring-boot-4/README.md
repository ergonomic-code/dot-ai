# Spring Boot 4 Migration Knowledge Base (Snapshot)

This directory contains a curated snapshot of Spring Boot 3.5 to Spring Boot 4 migration issues and patterns.
This snapshot is inlined into a Codex skill and intentionally omits raw evidence artifacts.

## Contents

`index.yaml` lists issues and patterns.
`issues/` contains one issue per root cause.
`patterns/` contains recurring migration patterns across issues.

## Limitations

This snapshot does not include raw commit diffs, build logs, or signature extraction artifacts.
Use it as a practical fix playbook rather than a full traceability bundle.
